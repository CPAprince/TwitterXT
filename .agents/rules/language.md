# Repository Language & Documentation Rule

## Core Requirement
All content stored in the repository MUST be in **English**:
1. **Documentation**: Any `.md` file, user guide, deployment instruction, or API documentation must be written in English.
2. **Code & Comments**: All code comments, docblocks (PHPDoc, JSDoc), variable names, and commit messages must be in English.
3. **Conversational vs Repository Language**: While conversational responses in chat may be conducted in Russian or Ukrainian as requested by the user, all persisted artifacts, repository files, commit messages, and PR descriptions must be strictly in English.
